# 可选增量向量检索

先在 AstrBot 配置并验证 Provider，再填写现有 ID；不要在插件中填写 API Key。公开默认禁用。插件启动可能早于 Provider，后台最多等约 60 秒，超时保留词法检索。

就绪后约 5 秒首次扫描，常规间隔 1800 秒，每批最多 16 条；保存、纠正、合并、遗忘会唤醒。仅正式有效、非敏感标记的条目参与；正文不变复用向量。遗忘/失效文档退出索引。模型变化不等于切换聊天模型。

私人正式条目可能发送给外部 Provider，开启前应取得同意并确认数据政策。原始 sources 和完整聊天档案不被批量向量化。

查询缓存约 1 小时、128 项，键包含模型、Agent、actor、可读域与查询 HMAC，不跨身份复用结果。等待 0.6 秒超时后先走词法，尚未完成的请求不会立即重发。错误无自动重试，冷却约 5 分钟。

默认每日 500 次、200000 UTF-8 字节，按北京时间日期持久预留；包含失败预留，不是成功账单。新增文档和未命中缓存的查询都消耗额度。相似度默认至少 0.78、最多 3 条，仍受注入预算约束。

费用按文档和查询实际 Token 及渠道报价估算；若向量输出另收费，用实际账单单位，不能把字节或维度当 Token。权重衰减、归档与工具清理不调用 Embedding。

备份向量库及匹配配置；不要在插件运行中另起 CLI 写入，也不要无故全库重建。
