# 架构与激活权重

近期上下文、正式记忆、完整原文、技术记录分层。后两者目前共用档案数据库，不是物理分库；普通搜索排除工具参数和返回。HMAC 来源、Markdown ACL、证据引用与遗忘标记保留。身份检查先于 FTS/图谱/向量读取和排序，返回前重新检查当前文档状态。

`activation_enabled` 默认关闭。初始强度 7 天：

```text
activation = max(floor, exp(-unused_days / strength_days))
普通检索评分 *= 0.35 + 0.65 * activation
```

fact、relationship 或 importance>=0.8 的底值为 0.4，其他为 0.05。明确回忆关键词加足够原词重合时，每条每天最多强化一次，强度乘 1.5，最大 90 天。单纯检索/注入不强化；已遗忘、过期或无权限条目不能被强化复活。

这不是事实正确性概率，不是神经网络学习。重复也可能强化错误，纠正仍应走 correct/forget。没有“任务实际完成质量”的自动判定器；图谱仍使用已有带来源实体和边，不自动跨身份传播激活。

档案按 agent/ns/cid/digest/occurrence 保存 Message JSON，同文重复次数保留，snapshot 记录顺序，精简版本可成为新版本。历史缺少逐条时间戳时只记录归档时间，不伪造发生时间。

先保存原文再整理后续请求，不在后台批量改写聊天库。到期图片先落地，失败保留；年轻图片可以使预算超出。旧历史用有限原文摘录交接，不调用额外摘要模型，不保证完整语义。

向量键为 agent/ns/digest/model。仅正文或模型改变需要新向量；权重变化不改 digest。只索引正式有效条目，不索引 sources 或整个原文档案。实际计费仍由渠道账单决定。
